# Sprint Change Proposal — 2026-10-16

**Project:** agenticexperience.net · **Author:** Claude (Correct Course) · **Mode:** Incremental · **Scope:** Moderate

## 1. Issue Summary

Epics 1–22 are done. The backlog is empty apart from story 20.5 (live-model runs), which is blocked on API keys. The roadmap step "adoption, then Python and Go ports" (2026-10-13) is finished. A next epic is needed.

**Evidence: Python and Go are behind .NET**

| Capability | .NET | Python | Go |
|---|---|---|---|
| Capture, verify, inject, erase, last-injected | yes | yes | yes |
| Semantic (vector) retrieval (21.3) | yes | no | no |
| Lessons view (21.4/21.8) | yes | no | no |
| OpenTelemetry | yes | no | no |
| Published package | NuGet | no (PyPI publisher pending) | no (tags pending) |

Without vectors, recall on reworded and realistic queries was 0 in the 20.1 benchmark. Python and Go users therefore get the weakest form of retrieval.

`RELEASING.md` also builds the version string as `prefix-suffix` every time. With no suffix, as at 1.0, that produces `1.0.0-`. The version rule is written out inline three times, and no test checks the third copy.

## 4. Detailed Change Proposals

### 4.1 `epics.md`: append Epic 23 (approved)

```
## Epic 23: Python and Go Users Get What .NET Users Get

Epic 22 gave the ports the full capture–verify–inject loop, but a Python or Go
MAF developer still gets less than a .NET one: text-only retrieval (paraphrase
recall 0 in 20.1), no way to see what was learned, no telemetry, and no
published package. This epic closes those gaps, in the order that most affects
whether a lesson reaches the agent.

### Story 23.1: Contract 1.6, Vector Search Calls
Depends on 22.10. Add-only: the hybrid text+vector search call, embedding
dimension/normalization rules, and fixtures generated by .NET with fixed
vectors (no model). Python and Go pass unchanged on everything else.

### Story 23.2: Python Semantic Retrieval
Depends on 23.1. Given an embedding callable registered with
use_agent_experience, retrieval is hybrid (in-memory and PostgreSQL+pgvector);
without one it falls back to text search observably, as in .NET 21.3. Passes
1.6; cross-language: a .NET-embedded record is found by a Python query.

### Story 23.3: Go Semantic Retrieval
As 23.2 for Go (go/postgres, go/inmemory, go/maf).

### Story 23.4: See What It Learned, in Python and Go
As 21.4/21.8: list lessons in the caller's scope with status, confidence,
checks, rendered block text and last-injected instant; output equals .NET's
for the same rows (new contract fixture family if needed).

### Story 23.5: Port Telemetry
OpenTelemetry spans/metrics with the same names and attributes as
docs/telemetry.md (optional dependency in Python, separate module in Go); a
test pins names against the .NET list.

### Story 23.6: 1.0-Safe Release Scripts
Fix RELEASING's prefix-suffix build so an empty suffix yields 1.0.0; one
tested version-derivation rule replaces the three inline copies.
```

Out of scope: Go encryption. It isn't needed to share lessons. Log it in deferred-work.
